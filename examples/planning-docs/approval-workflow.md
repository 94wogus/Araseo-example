# 문서 결재 워크플로우

회사 내 문서 승인 프로세스를 나타내는 플로우차트입니다.

## 개요

직원이 작성한 문서가 팀장, 부서장을 거쳐 최종 승인되는 과정을 시각화합니다.

## 프로세스

### 1단계: 문서 작성
- 작성자가 문서 초안 작성
- 제목, 내용, 첨부파일 포함

### 2단계: 팀장 검토
- 팀장이 문서 내용 검토
- 승인 또는 반려 결정
- 반려 시 수정 의견 첨부

### 3단계: 부서장 승인
- 팀장 승인 후 부서장에게 전달
- 최종 승인 또는 반려
- 반려 시 팀장에게 회신

### 4단계: 완료
- 승인 완료 시 문서 아카이브
- 관련자 전원에게 알림 발송

## 플로우

```
시작 → 문서 작성
   ↓
팀장 검토
   ↓
승인? ─[반려]→ 수정 의견 → 문서 수정 ↺
   ↓[승인]
부서장 검토
   ↓
최종 승인? ─[반려]→ 재검토 → 팀장 검토 ↺
   ↓[승인]
문서 아카이브 → 알림 발송 → 종료
```

## 예외 처리

- 7일 이상 미결 시 자동 알림
- 긴급 문서는 부서장 직접 검토 가능
