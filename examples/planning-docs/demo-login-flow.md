# 로그인 플로우 기획서

## 플로우 설명
사용자가 앱에 로그인하는 과정을 표현한 플로우차트입니다.

## 노드 구성

### 1. 시작
- 사용자가 앱 실행

### 2. 로그인 화면
- 이메일/비밀번호 입력 폼 표시

### 3. 인증 확인
- 입력된 정보로 서버 인증 요청

### 4. 인증 성공?
- 성공: 메인 화면으로 이동
- 실패: 에러 메시지 표시

### 5. 메인 화면
- 사용자 대시보드 표시
- 종료

### 6. 에러 메시지
- "로그인 실패. 다시 시도해주세요."
- 로그인 화면으로 돌아가기

## 플로우 연결
```
시작 → 로그인 화면 → 인증 확인 → 인증 성공?
                                    ↓(성공)    ↓(실패)
                              메인 화면    에러 메시지
                                 ↓              ↓
                               종료      로그인 화면
```
