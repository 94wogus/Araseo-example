# 전자상거래 결제 프로세스

온라인 쇼핑몰의 결제 플로우를 나타냅니다.

## 배경

사용자가 장바구니에 담은 상품을 결제하는 전체 과정을 시각화합니다.

## 주요 단계

### 1. 장바구니 확인
- 상품 목록 확인
- 수량 조정 가능
- 쿠폰 적용

### 2. 배송지 입력
- 수령인 정보
- 주소 입력
- 배송 메모

### 3. 결제 수단 선택
- 신용카드
- 계좌이체
- 간편결제 (카카오페이, 네이버페이)

### 4. 결제 진행
- PG사 연동
- 결제 승인 대기
- 성공/실패 처리

### 5. 주문 완료
- 주문 번호 발급
- 확인 이메일 발송
- 배송 준비

## 프로세스 플로우

```
시작
  ↓
장바구니 확인
  ↓
상품 있음? ─[없음]→ 쇼핑 계속하기 → 종료
  ↓[있음]
배송지 입력
  ↓
유효한 주소? ─[아니오]→ 재입력 ↺
  ↓[예]
결제 수단 선택
  ↓
결제 진행
  ↓
PG사 승인
  ↓
승인 성공? ─[실패]→ 실패 안내 → 재시도/취소
  ↓[성공]
주문 번호 발급
  ↓
확인 이메일 발송
  ↓
배송 준비 → 종료
```

## 에러 처리

- 결제 실패 시 3회까지 재시도 가능
- 타임아웃 30분 (세션 유지)
- 재고 부족 시 실시간 알림
