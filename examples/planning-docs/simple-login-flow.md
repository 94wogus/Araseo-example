# 간단한 로그인 플로우

사용자가 로그인을 시도하는 기본 프로세스입니다.

## 프로세스 단계

1. **시작** - 사용자가 로그인 페이지에 접속
2. **입력** - 이메일과 비밀번호 입력
3. **검증** - 서버에서 자격증명 확인
4. **분기** - 인증 성공 여부 판단
5. **성공 시** - 홈 대시보드로 리다이렉트
6. **실패 시** - 에러 메시지 표시 후 재입력

## 플로우 다이어그램

```
시작
  ↓
이메일/비밀번호 입력
  ↓
서버 인증 확인
  ↓
성공 여부?
  ├─ 성공 → 대시보드 이동 → 종료
  └─ 실패 → 에러 메시지 → 재입력
```

## 특이사항

- 3회 연속 실패 시 계정 임시 잠금 (추후 구현)
- 비밀번호는 암호화되어 전송
