# 대시보드 UI 목업

관리자 대시보드 화면입니다.

## 전체 레이아웃

3단 구조: 헤더 + 사이드바 + 메인

### 헤더 (Header)
- **좌측**: 로고 + 프로젝트명 "Araseo Dashboard"
- **우측**:
  - 알림 아이콘 (배지 3개)
  - 사용자 프로필 드롭다운

### 사이드바 (Sidebar)
네비게이션 메뉴

#### 메뉴 항목
1. 홈 (아이콘: home)
2. 프로젝트 (아이콘: folder)
3. 작업 (아이콘: check-square)
4. 팀원 (아이콘: users)
5. 설정 (아이콘: settings)

### 메인 컨텐츠 (Main)

#### 상단 요약 카드 (Grid 4개)
1. **총 프로젝트**
   - 숫자: 24
   - 전월 대비: +12%

2. **진행중 작업**
   - 숫자: 87
   - 전월 대비: -5%

3. **완료율**
   - 숫자: 73%
   - 전월 대비: +8%

4. **팀원 수**
   - 숫자: 12
   - 변동: 0

#### 최근 활동 (Table)
컬럼:
- 작업명
- 담당자
- 상태
- 마감일
- 액션 (보기/수정/삭제)

샘플 데이터 3-5개 표시

#### 차트 섹션
- 월별 작업 완료 추이 (Line chart)
- 프로젝트별 진행률 (Bar chart)
