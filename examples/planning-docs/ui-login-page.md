# 로그인 페이지 UI 목업

간단한 로그인 화면 디자인입니다.

## 레이아웃

### 헤더
- 로고 (좌측 상단)
- 회사명: "Araseo"

### 메인 컨텐츠
중앙 정렬된 로그인 폼

#### 로그인 폼 구성
1. **제목**: "로그인"
2. **이메일 입력 필드**
   - Label: "이메일"
   - Placeholder: "your@email.com"
   - Type: email
   - Required: true

3. **비밀번호 입력 필드**
   - Label: "비밀번호"
   - Placeholder: "********"
   - Type: password
   - Required: true

4. **옵션**
   - 로그인 유지 (Checkbox)

5. **버튼**
   - 로그인 (Primary button)
   - 회원가입 (Secondary button)

6. **링크**
   - "비밀번호를 잊으셨나요?"
