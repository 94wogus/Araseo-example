# 상품 카드 UI 목업

전자상거래 상품 카드 컴포넌트입니다.

## 컴포넌트 구조

### 상품 카드 (Product Card)

Grid 레이아웃으로 3-4개씩 배치

#### 카드 내부 구성

1. **이미지 영역**
   - 상품 썸네일
   - 비율: 1:1 (정사각형)
   - 우상단: 찜하기 아이콘 (하트)
   - 좌상단: 할인 배지 (있을 경우)

2. **정보 영역**
   - **브랜드명**: 작은 텍스트, 회색
   - **상품명**: 중간 텍스트, 굵게, 2줄 제한
   - **평점**: ★★★★☆ (4.5) 리뷰 120개

3. **가격 영역**
   - **할인가**: 큰 텍스트, 굵게, 빨간색
   - **원가**: 작은 텍스트, 회색, 취소선
   - **할인율**: 배지 형태 "%"

4. **액션 영역**
   - **장바구니 담기** 버튼: Primary
   - **바로 구매** 버튼: Secondary
